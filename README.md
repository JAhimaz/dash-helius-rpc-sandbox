# DASH — Solana Workflow Builder

A visual workflow builder for composing and executing Solana RPC calls using the [Helius](https://www.helius.dev/) API. Chain multiple RPC methods together, pipe outputs between nodes, and inspect results — all from an interactive node graph.

## Features

- **Visual Node Graph** — Drag-and-drop canvas powered by React Flow. Connect nodes, visualize data flow, and execute workflows in order.
- **67+ RPC Methods** — Auto-generated registry covering Solana RPC, DAS (Digital Asset Standard), Wallet API, and ZK Compression endpoints.
- **Special Utility Nodes** — Built-in nodes for common data operations:
  - **WebSocket** — Real-time Solana subscriptions
  - **Arithmetic** — Math operations (add, subtract, multiply, divide)
  - **Filter** — Filter arrays using path expressions
  - **Value Aggregator** — Aggregate values across nodes (sum, avg, min, max, count)
  - **List** — Iterate over arrays and fan out to downstream nodes
- **Reference System** — Map any node's output fields as inputs to other nodes using JSONPath-style references.
- **Repeat & Loop** — Configure nodes to repeat execution on an interval with loop counts.
- **Gatekeeper** — Optional beta RPC routing via `beta.helius-rpc.com` for enhanced request handling.
- **Import / Export** — Save and restore workflows as JSON, optionally including node outputs.
- **Console** — Built-in log viewer for inspecting RPC requests and responses.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18+ or [Bun](https://bun.sh/)
- A [Helius API key](https://www.helius.dev/) (free tier available)

### Install

```bash
git clone https://github.com/JAhimaz/dash-helius-rpc-sandbox.git
cd dash-helius-rpc-sandbox
npm install
# or
bun install
```

### Run

```bash
npm run dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Usage

1. Paste your Helius API key in the input field at the top.
2. Select your network (Mainnet or Devnet).
3. Click **Add Node**, search for an RPC method, and add it to the canvas.
4. Configure node parameters in the settings dialog (click the gear icon on a node).
5. Use **Reference** mode on any parameter to pipe output from another node.
6. Execute with the play button on the canvas toolbar — nodes run in dependency order.
7. Inspect outputs in the node settings dialog or the Console panel.

## Updating the Method Registry

The RPC method registry is auto-generated by scraping the Helius API docs:

```bash
bun scripts/generateMethodRegistry.ts
```

This outputs `src/lib/generatedMethodRegistry.json` with method names, parameter schemas, and response types.
